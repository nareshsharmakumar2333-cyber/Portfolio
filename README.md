# Naresh Sharma Portfolio

A responsive personal portfolio website built with Bootstrap 5, HTML5, CSS3 and JavaScript.

## Files
- `index.html` - complete portfolio page
- `style.css` - custom design and responsive styling
- `script.js` - navbar active state, mobile menu, back-to-top and contact form
- `assets/` - optional assets folder

## Run locally
Just double-click `index.html` or open it in VS Code with Live Server.

## Deploy on GitHub Pages
1. Create/open a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and the `assets` folder.
3. Go to Settings -> Pages.
4. Under Build and deployment choose `Deploy from a branch`.
5. Select `main` and `/ (root)`.
6. Save.
7. Your website will be published on the GitHub Pages URL.

## Important
The contact form uses `mailto:` and opens the visitor's email application. For a real online form without opening email software, connect it later to Formspree, EmailJS, Brevo or your own PHP backend.
